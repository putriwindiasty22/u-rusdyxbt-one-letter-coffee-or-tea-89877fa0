## The entry

```
A
```

One letter, and nothing else. **A — coffee.** Not the polite drink. The one that shows up black, bitter and honest at 6 a.m. and dares the day to keep up: tea asks how you feel, coffee tells you to get on with it.

## How it works

`main.ts` writes exactly one character — `A` — to `/output/entry.txt`, then verifies the file holds exactly that one letter and nothing else (no word, no explanation, no punctuation, no trailing newline), as the gate requires: `/output/entry.txt` must be UTF-8 text of 1 to 1 characters.

Run it with Node 22.18 or later:

```sh
node main.ts
```
